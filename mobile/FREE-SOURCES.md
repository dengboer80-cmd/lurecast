# 免费天气、潮汐与地图来源核验

核验时间：2026-10-27。通过官方文档和真实公开接口检查，结果可在仓库 Actions 的“Research free weather tide and map sources”及发布工作流中复核。没有把“免费试用”当作永久不限额服务，也没有把海洋模型冒充潮位站潮表。

当前5人、非商业测试符合所选天气免费API的用途；若改变使用性质或规模，需重新核对供应商条款。数据署名保留在应用中。所有地图和天气来源都不证明某地允许垂钓。

## 真实接口结果

- 杭州（30.2741,120.1551）：天气接口 HTTP 200，返回2026-10-27至2026-11-05完整10天。
- 舟山（29.91,122.38）：海洋接口 HTTP 200，240个小时中224个有有效海平面值，缺失16小时未补齐。
- 杭州同一位置：海洋接口 HTTP 200，但240小时全部为空。界面明确显示不可用，不生成杭州潮汐曲线。
- 以上记录是当次检查，不是对后续每次请求成功或覆盖的保证。代码每次仍校验返回字段、网格位置和有效数据。

没有确认可供当前杭州/钱塘江直接使用、长期免费且可靠授权的本地站潮表接口，所以该项仍不能称为已接通。全球免费海洋模型与钱塘江涌潮/河道水位是不同数据，不能相互替代。

## 当前实现

### 天气与海洋

直接请求Open-Meteo，不需要苹果开发者会员、Key或独立签名后端。每个位置在内存缓存10分钟。保留真实返回的日期、数值、缺失和获取时间；海洋曲线在缺失时段断开，不插值，不计算伪高潮/低潮。

发布工作流每3小时尝试获取杭州天气、杭州海洋和舟山海洋的实际响应，供接口不可用时使用公开同源缓存。只有通过校验的真实响应会被写入。客户端只接受位置相同、3小时内的缓存，并明确标记“最近发布缓存”；过期缓存不展示。GitHub定时任务可能延迟，不能当作实时站点监测。杭州海洋全空不会被转换成可用缓存。

缓存只包含上述公共参考位置，不上传用户私有钓点、收藏或计划。外部天气请求只在选择位置/刷新时发送所需坐标。地图瓦片、外部天气API均不由Service Worker预缓存。

### 鱼种库与删除模块

移除“鱼种与我的鱼获”的鱼获表单、重量、照片、统计和编辑删除功能，导航改为“鱼种库”。保留97项参考与自定义补录，每项均有原创2D艺术示意图；翘嘴鲌和中国花鲈保留原画法。不把示意图当作准确生物鉴定材料。

旧鱼获/照片本机数据库不再读取，也不会在这次界面删除中自动抹掉；不上传、不迁出个人设备。公开部署中删除旧journal.js脚本。旧的WeatherKit后端代码只保留作历史可选实现，不再用于当前默认免费天气流程。
