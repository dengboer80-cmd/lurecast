# 全国地点与鱼种扩展（2026-10-29）

本次改动在现有 Capacitor iPhone 工程和网页安装版中共用。

## 已实现

- 天气、未来15天、鱼种指数共用全国地点选择器。按省级地区筛选，地名搜索来自 Open-Meteo Geocoding / GeoNames，同名地点展示行政区和 WGS84 坐标供用户核对。列出34个省级地区选项，不宣称地名数据库覆盖每一个村庄。
- 未收录位置可输入坐标，手机定位仅在用户点击时请求。最近8个地点保存在本机；不后台定位。切换地点清空旧天气，迟到响应不能覆盖新地点，手动水温按坐标与日期隔离。
- 97条鱼种记录（含俗名、海外管理钓场对象、偶然路亚对象），可搜索、筛选、每页12条。不是全球或中国的穷尽物种表，也不证明本地存在此鱼。沿用原六个鱼种的实验参数，新增记录使用明确标注的类群实验参数。鱼种、水域和实际天气输入共同决定评分。缺水温/风速不评分，不拿气温当水温。
- 7张各3×5网格的写实3D渲染插画，97个独立图位；静态AI插画，不是可旋转3D模型、科学鉴定图或真实鱼种照片。

## 数据与免费范围

1. 天气 https://open-meteo.com/en/docs 。全球坐标覆盖，15天天气请求已设置 forecast_days=15，字段缺失保留空值，未来预报不是观测。
2. 地名 https://open-meteo.com/en/docs/geocoding-api 。language=zh，countryCode 精确过滤，CN/HK/MO/TW；中文行政区与坐标用于同名地点核对。按用户提交搜索，无自动逐字请求；成功结果内存缓存10分钟。
3. 授权 https://open-meteo.com/en/terms 。免费托管 API 仅限非商业用途，10000次/日、5000次/小时、600次/分钟；数据要求 CC BY 4.0 署名。不能据此承诺商业正式版免费。中国大陆手机网络访问质量尚需多运营商真机测试。

## 中国大陆潮汐继续检索结果

尚未核实到无需申请密钥、允许正式App复用、覆盖全国大陆站点的免费接口。保留已验证的香港天文台六站官方年表；不把香港覆盖或海洋模型说成大陆本地站潮表。

- 温州市水利局「温州水文潮汐水情信息」：https://data.wenzhou.gov.cn/jdop_front/detail/api.do?iid=6349 。小时级观测，字段 STCD / TM / TDZ。平台明确要求注册应用、申请审核，通过后用 appsecret 对接。观测不等同未来15天预测；文档未充分确认正式商业App的完整复用条款。不在客户端保存密钥。
- 温州高潮低潮预报： https://data.wenzhou.gov.cn/jdop_front/detail/api.do?iid=11110 ，同样需要申请授权，不能视为免Key接口。
- 星图地球潮汐API：https://open.geovisearth.com/support/document?docId=266 ，有大陆港口站点与预报，但需要认证账号与token，未验证潮汐接口免费额度与商业权利。底图免费额度不等于潮汐免费。
- 彩云潮汐：https://docs.caiyunapp.com/weather-api/v1/4-tide.html ，需要token/开通，近海预报时长有限，不能满足全国15天免费站表。
- 免费消费网站、宣传免费测试Key却没有可核实文档的服务，不纳入生产数据源。不抓取未获许可的内部接口。

## 发布边界

iOS 工程已同步资源；Linux环境只能完成结构校验，不能完成 Xcode 真机编译、签名、TestFlight 或App Store上架。正式商业发布前仍须确定天气商业授权、大陆潮汐授权和大陆网络可用性。鱼种评分属于未实钓校准的实验条件指数，非咬口概率。
