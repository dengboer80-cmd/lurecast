# LureCast 微信小程序工程

LureCast 原生微信小程序。当前仓库已配置 AppID 和云开发环境 ID。

已提供：全国地点搜索与WGS84坐标输入、用户主动定位、15天天气、体感/风向/日出日落/UV/近海模型水温、四列鱼种降序排名、40个国内候选与97条完整库、香港六站2026/2027官方潮表、微信账号同步钓点和出钓计划。

当前小程序首版不包含公共钓场地图、卫星图、Apple账号登录。网页和iOS工程保持原样。大陆本地潮位站尚未取得可用授权。

## 你现在先完成的事情

1. 打开[微信公众平台](https://mp.weixin.qq.com/)，选择注册“小程序”。
2. 按实际主办者选个人、企业或个体工商户；不得借用其他公司的主体。实名核验、相关协议确认和备案信息由账号主办者本人完成。
3. 注册完成后，在后台“开发管理/开发设置”一类的入口找到 **小程序AppID（wx开头）**。菜单名可能随平台调整。AppID不是AppSecret。
4. 把AppID和主体类型提供给开发协作者，继续绑定环境及上传。当前无需把身份证、密码、AppSecret或上传私钥放进仓库。

拟用名称：**LureCast 路亚天气**（是否可用以官方注册校验为准）。

拟用简介：**查询全国未来15天天气，按地点和鱼种查看路亚条件参考，查看已接入站点潮汐，并管理本机出钓计划。**

完整步骤见[REGISTER-AND-RELEASE.md](REGISTER-AND-RELEASE.md)。

## 导入工程

用微信官方[开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)导入本仓库的`wechat/`文件夹，入口是这里的`project.config.json`，不要只选择`miniprogram/`文件夹。工程已经带上共享规则、图片和官方潮表，导入不需要先编译网页。

无AppID时可尝试工具的测试/无AppID模式查看静态页面与本机功能，实际支持情况以工具为准。云开发、手机定位权限、真机预览和上传必须在真实账号下验证。未配置服务时页面明确提示不可用，不显示假天气。

## 数据服务

`miniprogram/config.js`填写已关联到小程序的微信云开发环境ID；在开发者工具或云控制台部署`cloudfunctions/lurecastData`，使用云端安装依赖。SDK固定为官方npm包`wx-server-sdk@4.0.2`。

云函数只接收`forecast`、`search`动作，使用固定服务域名，不转发任意URL。鉴权使用云开发会话，应用不存用户标识。相同请求缓存10分钟，暖实例按用户限制20次/分钟。**该限流为实例内辅助控制，不是跨实例全局额度控制**；公开上线前应在云平台配置用量监控、预算和适当的并发/调用限制。

云函数需要在控制台设置超时（建议30秒）及`ENABLE_PUBLIC_WEATHER=true`才启用天气。设置前须确认符合Open-Meteo免费托管API的非商业条款与当前调用额度；广告、付费等商业版不能沿用此免费许可。云开发套餐/计费以你实际开通页面为准，本工程没有开通或购买任何云资源。

使用`wx.cloud.callFunction`路径，客户端不直接调用外部天气域名，也不使用web-view；不要关闭`urlCheck`来掩盖正式环境问题。云函数的出网、数据源响应和中国各地微信网络仍需真实环境测试。

## 开发检查

在仓库根目录运行：

```sh
npm test --prefix wechat
npm run check:release --prefix wechat
node wechat/scripts/package.cjs
```

`prepare`从现有`mobile/scripts/`及`mobile/data/tides/`同步规则和原始年度表，不增加虚构鱼获数据。主包约0.88 MiB、潮汐分包约0.72 MiB（本地原始文件大小，微信实际编译包体由开发者工具核实）。`check:release`在缺少真实AppID或环境ID时会失败，这是发布前置条件提示，不是已经发布。

已验证范围：Node逻辑、页面事件逻辑、共享数据转换、包体预算、文件路由及事件绑定。**未运行微信开发者工具编译、云端真实部署、定位真机授权、微信审核或正式发布。**
