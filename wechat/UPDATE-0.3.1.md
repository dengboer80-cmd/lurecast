# 0.3.1 出钓日记与简化定位

## 更新

打开解压文件里的 wechat 文件夹，重新部署 cloudfunctions/lurecastData（上传并部署：云端安装依赖），然后重新编译真机预览。沿用原数据库 lurecast_records 和原有权限，不要删除数据库。验证后上传0.3.1提审。

## 使用

1. “我的出钓”→“记录一次出钓”。可搜索全国地点、使用手机定位，或从我的钓点选取；保留自定义钓点名称，不用输入经纬度。
2. 选择日期、开始时间，选取或自填目标鱼，填写可选鱼种分类、作钓分钟数、是否有口、是否中鱼和主要饵。
3. 自动记录当日所选时段的天气预报，非现场实测；可另填现场天气。历史日期未接入回溯，不会用当前天气代替。接口不通时可跳过获取，手填或保留“未获取”。
4. 保存后在我的出钓查看。相同地点同一天可以保存多次出钓日记，微信账号记录与本机记录仍分别保存。
5. 我的钓点可添加自定义鱼名（多种用逗号分隔）。自填鱼种仅记录，未建评分规则时不参与指数计算。

经纬度只在程序内部用于天气查询，不再要求用户输入，也不在钓点列表展示。未新增地图选点接口，继续使用已有地名搜索和手机定位能力。

天气连接修订（IPv4、10秒单次期限、超时阶段提示）随本版保留，但本地测试不代表实际云环境已经连通。请检查真机定位、微信记录同步、历史天气提示、同日多条日记和旧计划兼容性。
